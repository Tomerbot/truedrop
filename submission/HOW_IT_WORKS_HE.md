# איך TrueDrop עובד (כדי שתוכל להסביר לשופטים)

## הרעיון במשפט אחד
משחקים כותבים "סיכוי לאגדי: 0.6%", אבל אף אחד לא מרגיש כמה זה עולה. TrueDrop מריץ 100,000 שחקנים מדומים ומראה כמה כל אחד מהם שילם.

## החלקים בקוד
| קובץ | מה הוא עושה |
|---|---|
| `index.html` | המבנה של הדף: הטופס, הגרף, הקבלה והלשונית של "משיכה בחינם" |
| `css/style.css` | העיצוב. הצבעים הם צבעי הנדירות של המשחקים: כחול (נדיר), סגול, זהב (אגדי) |
| `js/sim-worker.js` | **הסימולציה.** רצה ב-Web Worker, כלומר "עובד" נפרד, כדי שהדף לא ייתקע |
| `js/crowd.js` | מצייר את "הקהל": כל נקודה היא קבוצה של שחקנים |
| `js/receipt.js` | מדפיס את הקבלה ושומר אותה כתמונה |
| `js/try.js` | מצב "משיכה בחינם" עם כסף מדומה |
| `js/rng.js` | מחולל מספרים אקראיים עם "זרע" (seed). אותו זרע = אותו מזל, כדי שאפשר לחזור על דמו |
| `js/app.js` | מחבר הכול: קורא את הטופס, שולח לסימולציה, מציג תוצאות |

## הטריק המתמטי (שאלה שהשופטים עלולים לשאול)
אפשר היה לדמות כל משיכה בנפרד: "הטל מטבע עם סיכוי 0.6%, שוב, ושוב...". זה איטי מאוד: 100,000 שחקנים כפול מאות משיכות.
במקום זה: מספר המשיכות עד הזכייה הראשונה מתנהג לפי **התפלגות גאומטרית**. יש לה נוסחה שנותנת את המספר ישר ממספר אקראי אחד:
`משיכות = ceil( ln(1 - U) / ln(1 - p) )`
כש-U הוא מספר אקראי בין 0 ל-1 ו-p הוא הסיכוי. אם יש "פיטי" (הבטחה אחרי 90 משיכות), פשוט לא נותנים למספר לעבור את 90.

## איך יודעים שזה נכון?
יש נוסחה מדויקת לממוצע: עם הבטחה אחרי N משיכות, הממוצע הוא `(1 - (1-p)^N) / p`. הקבלה מראה את הממוצע מהסימולציה ליד הממוצע מהנוסחה, והם כמעט זהים (למשל 139.28$ מול 139.40$).

## שאלות שהשופטים עלולים לשאול
- **"למה 100,000 שחקנים?"** מספיק כדי שהתוצאות יהיו יציבות (הפרש של פחות מאחוז מהנוסחה), ועדיין רץ בפחות משנייה.
- **"מה זה החציון?"** השחקן שבדיוק באמצע: חצי שילמו פחות, חצי שילמו יותר. זה "השחקן הרגיל". הממוצע גבוה יותר, כי כמה שחקנים חסרי מזל משלמים המון.
- **"למה יש עמודה ענקית בצד ימין?"** כי עם 0.6% והבטחה אחרי 90 משיכות, 58% מהשחקנים אף פעם לא זוכים במזל ומגיעים להבטחה. כולם משלמים בדיוק אותו מחיר, אז הם נערמים בעמודה אחת.
- **"הנתונים אמיתיים?"** הדוגמאות הן מספרים מומצאים, וכתוב את זה באתר. כל אחד מקליד את הסיכויים שהמשחק שלו מפרסם.
